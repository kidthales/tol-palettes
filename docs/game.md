# Game and Pixel-Art Outputs (Godot, GPL, Aseprite)

Generated by `npm run generate:game` and packaged via `npm run package:assets`:

- `dist/godot/addons/tol_palettes/`: Self-contained Godot 4.x addon folder containing `plugin.cfg`, `tol_palettes.gd`, and all 22 `ColorPalette` `.tres` resources.
- `dist/godot/tol_palettes.gd`: GDScript 2.0 (`class_name TolPalettes`) for Godot 4.x with `Color` constants (for officially named qualitative colours), `SCHEMES` dictionary (`PackedColorArray` + `PackedStringArray`), and static lookup helpers (`get_colors()`, `get_hex()`, `get_named()`, `get_discrete_rainbow()`).
- `dist/godot/<id>.tres`: Godot 4.x `ColorPalette` resource files (22 schemes) that can be loaded directly into the Godot Editor ColorPicker.
- `dist/gpl/<id>.gpl`: Standard GIMP Palette files (22 schemes), compatible with GIMP, Inkscape, Krita, and Aseprite.
- `dist/aseprite/<id>.gpl`: Aseprite palette files with Aseprite metadata header comments.
- `dist/assets/tol-palettes-godot.zip`: Downloadable zip archive containing the Godot 4.x addon (`addons/tol_palettes/`).
- `dist/assets/tol-palettes-aseprite.zip`: Downloadable zip archive containing all 22 `.gpl` palettes with Aseprite metadata tags.
- `dist/assets/tol-palettes-gpl.zip`: Downloadable zip archive containing standard `.gpl` palettes for GIMP, Inkscape, and Krita.

## Godot 4.x Installation & Usage

### Method 1: Drag-and-Drop Addon Installation (Recommended)

1. Download `tol-palettes-godot.zip` from the [latest GitHub Release](https://github.com/kidthales/tol-palettes/releases).
2. Extract the archive into your Godot project root. It will create or merge into your project's `addons/` directory:
   ```text
   res://addons/tol_palettes/
     ├── plugin.cfg
     ├── tol_palettes.gd
     ├── bright.tres
     ├── muted.tres
     └── ... (all 22 schemes)
   ```
3. Open your Godot project. The editor will automatically index the `.tres` resources and the `TolPalettes` class.

### Method 2: ColorPicker Palette Loading

1. In the Godot 4.x editor, open any `ColorPicker` or inspector property with a color swatch.
2. In the Presets / Palettes panel, click the menu button and choose **Load Palette**.
3. Select any desired `.tres` file (e.g. `res://addons/tol_palettes/bright.tres`).

### Method 3: GDScript API

The `TolPalettes` class is registered via `class_name` and `@tool`, available across your project:

```gdscript
# Access officially named colours via typed constants:
var player_blue: Color = TolPalettes.BRIGHT_BLUE
var alert_red: Color = TolPalettes.MUTED_RED

# Query color arrays:
var sunset_colors: PackedColorArray = TolPalettes.get_colors("sunset")
var bright_hex: PackedStringArray = TolPalettes.get_hex("bright")

# Discrete rainbow lookup (n = 1..23):
var bar_colors: PackedColorArray = TolPalettes.get_discrete_rainbow(5)
```

## Pixel-Art Editors (Aseprite, GIMP, Krita)

### Aseprite
1. Download `tol-palettes-aseprite.zip` from GitHub Releases and extract.
2. In Aseprite, click the Palette Options menu (top left above color palette) -> **Load Palette** (or **Preset**).
3. Select any `.gpl` file (e.g. `bright.gpl`).

### GIMP / Inkscape / Krita
1. Download `tol-palettes-gpl.zip` from GitHub Releases and extract.
2. Copy the `.gpl` files into your application's palette directory:
   - **GIMP**: `~/.config/GIMP/2.10/palettes/` (Linux) or `%APPDATA%\GIMP\2.10\palettes\` (Windows)
   - **Krita**: Settings -> Manage Resource Libraries -> Import Palettes

## Naming Policy
Colour names appear in `.gpl` labels and GDScript constants **only** when the official `tol_colors.py` module defines them (the 6 qualitative schemes: `bright`, `high-contrast`, `vibrant`, `muted`, `medium-contrast`, `light`). Unnamed stops use their `#RRGGBB` hex value in `.gpl` and indexed `PackedColorArray` entries in Godot.

Every generated file includes an attribution header; see `NOTICE`.

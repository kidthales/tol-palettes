# Game and Pixel-Art Outputs (Godot, GPL, Aseprite)

Generated by `npm run generate:game`:

- `dist/gpl/<id>.gpl`: standard GIMP Palette files (22 schemes), compatible with GIMP, Inkscape, Krita, and Aseprite.
- `dist/aseprite/<id>.gpl`: Aseprite palette files with Aseprite metadata header comments.
- `dist/godot/tol_palettes.gd`: GDScript 2.0 (`class_name TolPalettes`) for Godot 4.x with `Color` constants (for officially named qualitative colours), `SCHEMES` dictionary (`PackedColorArray` + `PackedStringArray`), and static lookup helpers (`get_colors()`, `get_hex()`, `get_named()`, `get_discrete_rainbow()`).
- `dist/godot/<id>.tres`: Godot 4.x `ColorPalette` resource files (22 schemes) that can be loaded directly into the Godot Editor ColorPicker.

## Naming Policy
Colour names appear in `.gpl` labels and GDScript constants **only** when the official `tol_colors.py` module defines them (the 6 qualitative schemes: `bright`, `high-contrast`, `vibrant`, `muted`, `medium-contrast`, `light`). Unnamed stops use their `#RRGGBB` hex value in `.gpl` and indexed `PackedColorArray` entries in Godot.

Every generated file includes an attribution header; see `NOTICE`.

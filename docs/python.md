# Python output & PyPI Distribution

Generated by `npm run generate:py` into `dist/py/tol_palettes.py` and distributed on PyPI as [`tol-palettes`](https://pypi.org/p/tol-palettes).

## Installation

Install the package directly from PyPI:

```bash
pip install tol-palettes
```

If you need `matplotlib` colormap integration (`tol_cmap`, `discretemap`), install with the optional `matplotlib` extra:

```bash
pip install "tol-palettes[matplotlib]"
```

## Features
- **Zero required dependencies**: Pure Python standard library (`collections.namedtuple`) for accessing all 22 scheme hex tuples and `tol_cmap_colors()`.
- **Optional `matplotlib` support**: `tol_cmap()` and `discretemap()` lazily import `matplotlib` and `numpy` only when called.
- **Official `tol_colors.py` compatibility**:
  - `tol_cset(name)` returns a `namedtuple` with the official field names and hex strings for the 6 qualitative sets (`bright`, `high-contrast`, `vibrant`, `muted`, `medium-contrast`, `light`).
  - For site-only discrete schemes (`dark`, `pale`, `groundcover`), `tol_cset(name)` returns a plain tuple of `#RRGGBB` strings (no colour names are invented).
  - `tol_cmap(name, lut=None)` supports all 17 official colormaps (`sunset`, `sunset_discrete`, `nightfall`, `nightfall_discrete`, `BuRd`, `PRGn`, `YlOrBr`, `WhOrBr`, `iridescent`, `rainbow_PuRd`, `rainbow_PuBr`, `rainbow_WhRd`, `rainbow_WhBr`, `rainbow_discrete` with `lut=1..23`) plus the site-only sequential schemes (`incandescent`, `incandescent_discrete`, `banded_12`, `banded_16`, `banded_20`).
- **Attribution**: Includes the full 3-clause BSD copyright notice and disclaimer in the module docstring; see `NOTICE`.

## Quickstart

```python
import tol_palettes
from tol_palettes import tol_cset, tol_cmap, tol_cmap_colors

# Access qualitative colour sets
bright = tol_cset("bright")
print(bright.blue)  # "#4477AA"
print(bright._fields)  # ('blue', 'red', 'green', 'yellow', 'cyan', 'purple', 'grey', 'black')

# Access colour maps (with matplotlib installed)
sunset_cmap = tol_cmap("sunset")
```

## Build & Packaging Details
- **Build backend**: `hatchling` (PEP 517/621) configured in `pyproject.toml`.
- **Module mapping**: `dist/py/tol_palettes.py` is packaged as a top-level module `tol_palettes` inside both wheels and source distributions.

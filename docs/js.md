# JavaScript / TypeScript and JSON output

Generated by `npm run generate:js`:

- `dist/json/schemes.json`: single JSON bundle containing `$comment` (attribution) and `schemes` (`Record<SchemeId, Scheme>`). Every entry validates against `schema/scheme.schema.json`.
- `dist/js/index.js`: side-effect-free, tree-shakeable ESM module exporting each scheme as a named constant, a `schemes` dictionary, `schemeList`, and interpolation/lookup helpers.
- `dist/js/index.d.ts`: TypeScript type declarations for `dist/js/index.js`.

## Exports (`dist/js/index.js`)

| Export | Description |
|---|---|
| `bright`, `highContrast`, `sunset`, `iridescent`, ... | Individual camelCase scheme constants (22 schemes). |
| `schemes` | Record keyed by canonical kebab-case scheme `id` (`'bright'`, `'high-contrast'`, ...). |
| `schemeList` | Array of all 22 scheme objects sorted by `id`. |
| `get(id)` | Returns the scheme object for `id`, or `undefined` if unknown. |
| `getScheme(schemeOrId)` | Returns the scheme object, or throws `RangeError` if unknown. |
| `interpolate(schemeOrId, t, options?)` | Linearly interpolates in sRGB at `t` in `[0, 1]` for schemes with `interpolation: 'linear' \| 'either'`. Supports `{ subrange }` (e.g. `'rainbow_PuRd'`). |
| `sample(schemeOrId, count, options?)` | Samples `count` evenly spaced `#RRGGBB` stops across `[0, 1]`. |
| `discreteRainbow(n)` | Returns the `n`-colour array (`1 <= n <= 23`) from `rainbow-discrete.lut`. |
| `discreteRainbowBad(n)` | Returns `'#777777'` at `n === 23`, `'#FFFFFF'` for `1 <= n <= 22`. |
| `discreteColors(schemeOrId, n?)` | Returns the discrete colour list (`lut[n-1]` if `lut`, `discreteIndexes` subset if defined, else all `colors`). |
| `hexToRgb(hex)` / `rgbToHex(r, g, b)` | sRGB `#RRGGBB` conversion helpers. |

Every generated file starts with an attribution header; see `NOTICE`.

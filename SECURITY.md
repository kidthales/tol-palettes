# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `@kidthales/tol-palettes`, please report it privately via [GitHub Security Advisories](https://github.com/kidthales/tol-palettes/security/advisories/new) rather than opening a public issue. We will review and respond promptly.
